# anki_func_fullstack

Финальный проект спринта «Карты Anki».

В этом сервисе пользователи заучивают иностранные слова, просматривая карточки. Реализация проекта — отличный способ закрепить изученное в этом спринте: работу со словарями, циклами, файлами, строками и пользовательским вводом.

## Цель проекта

Ваша цель — реализовать интерактивное консольное приложение для тренировки словарного запаса.

## Возможности программы

Пользователь может:

* проходить тренировки по переводу слов;
* добавлять новые слова в свой словарь;
* просматривать весь словарь;
* сохранять и загружать словарь из файла.

## Структура хранения данных

Все слова хранятся в виде словаря Python:

```python
words = {
    'яблоко': 'apple',
    'кот': 'cat',
    # ...
}
